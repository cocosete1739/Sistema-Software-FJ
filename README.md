# Sistema Integral de Gestión de Clientes, Servicios y Reservas - Software FJ
**Curso:** Programación (213023) - Fase 4  
**Universidad Nacional Abierta y a Distancia (UNAD)**  

## Descripción
Aplicación orientada a objetos desarrollada en Python que simula la gestión de clientes, servicios y reservas para la empresa Software FJ, implementando un manejo robusto de excepciones, bloques estructurados (`try/except/else/finally`), excepciones personalizadas y registro de logs sin utilizar bases de datos.

## Estructura del Proyecto
- `excepciones.py`: Clases de excepciones personalizadas.
- `logger.py`: Sistema de registro de eventos y errores en archivo `.log`.
- `modelos.py`: Arquitectura POO (clases abstractas, cliente, servicios y reservas).
- `main.py`: Módulo de ejecución con la simulación de las 10 operaciones.
